# Trabalho Prático – Meta-heurísticas (CCF-480)

## Descrição

Este trabalho consiste na implementação de um algoritmo baseado em uma **meta-heurística cooperativa (Inteligência Coletiva)** para resolver:

* o **Problema 1 do TP1** (configuração **a**);
* o **Problema 1 do TP2**, utilizando uma estratégia para tratamento da restrição.

Para cada problema, o algoritmo foi executado **30 vezes de forma independente**. Com os resultados obtidos, foram calculados:

* valor mínimo;
* valor máximo;
* média;
* desvio padrão.

Além disso, foram gerados **boxplots** para análise dos resultados e identificadas as melhores soluções encontradas, apresentando os respectivos valores das variáveis de decisão.

Neste repositório encontram-se o código-fonte desenvolvido, o relatório do trabalho e os resultados obtidos durante os experimentos.
